# 提示词版本变更记录

`PROMPT_VERSION` 是 KV 缓存前缀的一部分：**改提示词必须 bump**（AGENTS.md §4.5、docs/07 §4）。
本文件只追加，不覆盖；更早版本以 `version.ts` 与各提示词文件首部标注为准。

| 版本 | 日期 | 改了什么 | 为什么 |
|---|---|---|---|
| `2026-11-18.1` | 2026-11-18 | `turn.prompt.ts`：S1 硬规则增「只有在场者能说话/行动，不得替不在场者回答」；S7/S8 在多 NPC 场景按人分段并标 NPC 名（`林静（NPC）还记得…`）；`00-world-system.md` 增规则 10。 | issue #20 / #21：多 NPC 场景原先把 owner 退回玩家，两个 NPC 的私忆都不注入；模型还会替不在场者说话。 |
| `2026-11-17.3` | 2026-11-17 | S1 增「推进优先」硬规则（同场景第二次观察必须给新细节）。 | 模型重复描写环境、回合不推进。 |

## 2026-11-22.1（sim-v2：作者注 / 关键词世界设定）

- `buildTurnPrompt` 新增可选 `authorNote`（稳定前缀，单独成段）与 `worldInfo`（按当前输入/地点/在场者命中的世界设定条目，固定顺序）。
- 内容来自 `content/lorebook.json`（`apps/server/src/lorebook.ts` 读取与匹配）；缺文件时两段都不出现，提示词与旧版逐字节一致（除版本号）。
- 只影响“给 LLM 看什么”，不新增 op、不让 LLM 直接写状态；所有结果仍走 Proposal → Arbiter。
- 改动提示词前缀，按规则 bump `PROMPT_VERSION` 到 `2026-11-22.1`。
