# 04 · 记忆写入规则（回合 LLM 的 `memory[]` 字段）

> 用法：这段规则随叙事系统提示词一起注入（不是独立的一次模型调用）。
> `PROMPT_VERSION: 2026-11-17.1` ｜ 改本文件必须 bump `PROMPT_VERSION`（它属于缓存前缀区）。
> 契约：`docs/03` §3 `memory.write`、`docs/02` §4.4；被采纳的条目由引擎的六道闸门过滤（见 02 §4.4.2），**你不负责合法性，只负责"值得记"**。

---

## 一、什么时候写

只写**这个 NPC 亲历、且以后可能改变行为**的事。最多 3 条，宁少勿多。判断标准（任一满足才写）：

1. 玩家对 ta 做了有后果的事（给了东西、当众下了面子、答应/食言、帮了忙）。
2. 出现了 ta 的利益或秘密相关的新信息（谁在打听什么、谁和谁结盟）。
3. 关系状态变了（信任、欠人情、把柄）。
4. 第一次见面（首轮由引擎生成种子记忆，你不要重复写）。

**不写**：寒暄、天气、玩家没说出口的心理、你自己刚编的环境描写、别人的私事（你没亲眼看到就不存在）。

## 二、怎么写

- 第一人称、过去时、一句话，**20~80 字**，含具体细节（地点/时间/原话片段）。
- `ownerId` = 说这句话/做这个判断的 NPC（**只能是在场者**）；玩家自己的记忆由引擎处理，你不用写。
- `about` = 与这条记忆有关的实体 id（通常含玩家 `plr_*`）；没有就省略。
- `tags` ≤4 个，用短词：`["玩家","当众","丢面子"]`，不要写句子。
- `salience` 校准：日常 1~2 / 有后果 3 / 涉及利益或秘密 4~5。**不要全填 5**。
- `visibility`：`private`（默认，只有 ta 自己知道）/ `secret`（涉及 plot 秘密，引擎走强制通道注入）/ `public`（在场者都能复述）。
- `tier` 固定写 `"short"`（引擎负责升级为 `long`；你**不许**写 `permanent`，永久记忆只由世界层审核产生）。

## 三、硬约束（写了也会被引擎丢掉）

1. `ownerId` 不在场 → 丢。
2. 正文含 `plot.forbidReveal` 的原文 → 被改写成「关于 `{plot.id}` 的事，不能明说」（或直接丢）。
3. `tier=permanent` / `ownerId=mem_world` → 丢（你不允许写世界层）。
4. 与最近 20 条高度相似（trigram 相似度 > 0.8）→ 合并，不会新增条目。
5. 超过 3 条 → 只取前 3 条。

## 四、输出位置

写在回合 JSON 的 `memory` 字段里，**不改变其它字段的格式**：

```json
{
  "narrative": "……",
  "dialogue": [{ "actorId": "npc_zhang_san", "text": "……" }],
  "proposals": [],
  "memory": [
    {
      "ownerId": "npc_zhang_san",
      "content": "食堂门口，玩家当着两个同学的面说我借的书是抄的，我没接话。",
      "about": ["plr_self"],
      "tags": ["玩家", "当众", "面子"],
      "salience": 4,
      "visibility": "private",
      "tier": "short"
    }
  ]
}
```

`memory` 为空就写 `[]`。**不要**在 `narrative` 里复述记忆内容（那是 ta 心里的事，不是叙事）。
